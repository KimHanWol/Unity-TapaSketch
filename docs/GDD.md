# 타파아트 (TapaArt) 기획서

> 숫자를 보고 칸을 칠하면, 하나로 이어진 선화가 완성되는 로직 퍼즐.
> 이 문서는 "무엇을 만드는가"를 정의한다. 구현 방법은 [TECH.md](TECH.md)를 본다.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 앱 이름 | 타파아트 (스토어 제목 예: `타파아트: 숫자로 그리는 그림 퍼즐`) |
| 장르 | 캐주얼 로직 퍼즐 (타파 규칙 + 완성 시 그림 공개) |
| 플랫폼 | Android 우선 (Google Play), 이후 iOS 검토 |
| 화면 | 세로 모드 고정 |
| 엔진 | Unity |
| 타깃 | 네모로직·지뢰찾기·스도쿠를 즐기는 캐주얼 유저. 규칙을 처음 보는 사람도 튜토리얼로 5분 안에 이해 |
| 핵심 재미 | ① 숫자로 추리하는 손맛 ② 다 풀면 그림이 나오는 보상 ③ 길을 따라 올라가는 진행감 |
| 한 판 길이 | 초반 1~2분, 후반 5~10분 |

### 한 줄 설명 (스토어/튜토리얼용)
"지뢰찾기처럼 숫자로 추리하고, 네모로직처럼 칠해서 그림을 완성하세요."

## 2. 핵심 규칙 (타파)

1. 격자의 칸을 **검게 칠하거나** 비워 둔다.
2. **숫자 칸은 칠할 수 없다.**
3. 숫자는 **주변 8칸(대각선 포함)** 안에서 칠해진 칸이 **몇 개씩 이어져 있는지**를 나타낸다.
   - `3` → 주변에 3칸짜리 덩어리 하나
   - `1 2` → 1칸 덩어리 하나 + 2칸 덩어리 하나, 사이에 빈칸이 최소 1칸 (순서 무관)
   - `0` → 주변 전부 빈칸
4. 칠한 칸은 **상하좌우로 모두 하나로 이어져야** 한다.
5. **2x2로 꽉 칠해진 곳이 있으면 안 된다.**

### 이 게임만의 추가 요소
- 정답(칠한 칸 전체)이 곧 **하나의 선화 그림**이다. 모든 레벨의 정답은 사람이 알아볼 수 있는 그림이다.
- 퍼즐을 다 풀면 숫자와 표시가 사라지고 **그림만 남는 연출**이 나온다. 컬러는 넣지 않는다.
- 모든 레벨은 **해답이 하나뿐**이고, **추측 없이 논리로만** 풀린다.

## 3. 화면 흐름

```
[스플래시] → [타이틀] → [월드맵] ⇄ [게임] → [클리어] → [월드맵 or 다음 레벨]
                 ↘ [설정]      ↘ [설정/일시정지]
첫 실행: [타이틀] → [레벨 1 (튜토리얼)] 으로 바로 진입
```

### 3.1 타이틀
- 배경: 펼쳐진 스케치북. 로고 "타파아트"는 손글씨체.
- 로고 아래 작은 선화가 **스스로 칠해지며 완성되는 루프 애니메이션** (게임 설명 역할).
- `탭하여 시작` → 월드맵의 **현재 도전 레벨 위치**로 이동.
- 우상단: 설정 버튼.
- 첫 실행이면 월드맵을 건너뛰고 레벨 1 튜토리얼로 바로 들어간다.

### 3.2 월드맵 (애니팡식 레벨 길)
- **아래에서 위로** 올라가는 세로 스크롤 길. 길 위에 레벨 노드가 일정 간격으로 놓인다.
- 노드 상태
  - 잠김: 회색 자물쇠
  - 도전 가능(현재): 살짝 튀는 애니메이션, 캐릭터/연필 아이콘이 서 있음
  - 클리어: **완성한 그림의 작은 썸네일** + 획득한 별(0~3)
- 맵을 올라갈수록 완성한 그림이 길에 쌓여서, **맵 자체가 내 그림 컬렉션**이 된다.
- **챕터 = 스케치북 한 권.** 챕터 경계에 스케치북 표지(챕터 이름)가 나오고, 챕터마다 종이 색/잉크 색이 바뀐다 (아트 방향성 참고).
- 해금 조건: 직전 레벨 클리어 (별 개수로 막지 않음).
- 노드 탭 → 작은 팝업: 레벨 번호, 격자 크기, 최고 별, `시작` 버튼. (클리어한 레벨은 그림 이름도 표시)
- 상단: 설정 버튼, 보유 힌트 수.

### 3.3 게임 화면
```
┌─────────────────────────────┐
│ ←맵   챕터1 · 레벨 12     ⚙ │  상단 바
│                              │
│        ┌─────────────┐       │
│        │   격  자    │       │  중앙: 퍼즐 (큰 격자는 핀치 줌)
│        └─────────────┘       │
│                              │
│  ↶되돌리기  ↷다시  ⟲초기화    │
│   [ ■ 칠하기 | • 점 ]  💡3   │  하단: 입력 모드 토글, 힌트
└─────────────────────────────┘
```
- 타이머는 기본 숨김 (설정에서 켜기). 점수에 쓰지 않는다.
- 일시정지(⚙): 계속하기 / 처음부터 / 설정 / 맵으로.
- 앱을 나갔다 와도 **진행 중인 판은 그대로 복원**.

### 3.4 클리어
1. 마지막 칸을 맞추는 순간 입력 잠금.
2. 숫자와 점 표시가 페이드아웃.
3. 검은 칸들이 **한 붓으로 이어서 그리듯** 한 점에서 퍼져 나가며 다시 그려진다 (칠한 칸이 모두 연결돼 있다는 규칙을 연출로 보여줌).
4. 그림 이름이 손글씨로 등장 (예: "고양이").
5. 별 1~3개 등장.
6. 버튼: `다음 레벨` / `맵으로`. 맵으로 돌아가면 방금 노드에 썸네일이 찍히는 연출.

### 3.5 설정
| 항목 | 기본값 | 설명 |
|---|---|---|
| 효과음 | 켬 | |
| 배경음 | 켬 | |
| 진동 | 켬 | 칠할 때 가벼운 햅틱 |
| 규칙 위반 표시 | 켬 | 2x2, 숫자 초과, 끊긴 조각 등을 빨갛게 표시 |

## 4. 조작

- **탭**: 빈칸 → 칠함 → 점(비움 확정) → 빈칸 순으로 순환. (입력 모드가 `점`이면 빈칸 → 점 → 빈칸)
- **드래그**: 처음 누른 칸이 바뀐 상태를 드래그한 칸 전체에 똑같이 적용. 숫자 칸은 건너뜀.
- **입력 모드 토글**: `칠하기` / `점`. 초보자는 탭 순환만, 숙련자는 모드 토글+드래그를 쓴다.
- **되돌리기/다시**: 무제한. 드래그 한 번은 한 단계로 묶는다.
- **핀치 줌/이동**: 10x10 초과 격자에서 활성화.
- 칠할 때 짧은 연필 소리 + 가벼운 진동.

## 5. 보조 기능

### 5.1 규칙 위반 표시 (설정으로 끄기 가능)
정답과 비교하지 않고 **규칙만** 검사한다. 정답 누설 없이 실수를 알려주기 위함.
- 칠한 2x2 → 네 칸을 빨간 테두리로
- 숫자 조건이 이미 불가능해짐 (칠한 덩어리가 너무 길거나 개수 초과) → 숫자를 빨갛게
- 조건을 다 채운 숫자 → 흐리게
- 점으로 완전히 둘러싸여 다른 칸과 이어질 수 없는 칠한 덩어리 → 빨갛게

### 5.2 힌트
- 버튼을 누르면 **다음에 확정할 수 있는 칸 하나**를 반짝이고, 이유를 한 줄로 설명한다.
  - 예: "이 `7`은 주변 8칸 중 7칸이 이어져야 해요. 여기 한 칸만 비울 수 있어요."
- 플레이어가 **틀리게 칠한 칸이 있으면** 힌트는 먼저 그 칸을 알려준다.
- MVP에서는 설명 없이 "맞는 칸 하나 공개"로 시작해도 된다 (TECH.md 참고).
- 힌트 개수: 시작 3개. 획득: 보상형 광고 1회 = 1개, 챕터 클리어 = 2개.

### 5.3 별 평가
시간·실수로 벌점을 주지 않는다 (느긋한 퍼즐이 목표).
- ★★★ 힌트 0회
- ★★ 힌트 1~2회
- ★ 힌트 3회 이상
- 별은 맵 노드와 챕터 완료 화면에만 쓰인다. 해금 조건에는 쓰지 않는다.

### 5.4 하트/목숨 시스템: 넣지 않는다
애니팡식 하트는 로직 퍼즐과 궁합이 나쁘다 (틀려도 되돌리면 되는 게임이라 벌칙 기준이 애매함). 진행은 자유롭게, 수익은 광고/힌트로 낸다.

## 6. 레벨 구성

### 6.1 원칙
- **레벨 = 그림 하나.** 그림이 곧 정답이라 레벨마다 그림 이름이 있다.
- 2x2 금지 규칙 때문에 그림은 **면이 아니라 선(윤곽선)** 으로 그려진다. 작은 격자일수록 단순한 아이콘형(하트, 컵, 집)으로.
- 모든 레벨은 출시 전에 오프라인으로 **유일해답 검증 + 난이도 측정**을 거쳐 JSON으로 포함된다. (런타임 자동 생성 안 함)
- 난이도는 **톱니 모양**으로 올린다: 조금씩 어려워지다가 챕터 마지막 레벨이 큰 그림(보스 레벨), 다음 챕터 첫 레벨은 다시 쉽게.

### 6.2 챕터 계획 (출시 목표 150레벨)
| 챕터 | 레벨 | 격자 | 테마 예시 | 잉크/종이 |
|---|---|---|---|---|
| 1. 첫 스케치북 | 1~20 | 5x5 → 7x7 | 하트, 컵, 집, 나무, 물고기 | 연필 / 흰 종이 |
| 2. 동물원 | 21~45 | 7x7 → 8x8 | 고양이, 토끼, 거북이, 새 | 파란 볼펜 / 모눈 노트 |
| 3. 부엌 | 46~75 | 8x8 → 10x10 | 주전자, 포크, 케이크, 컵라면 | 사인펜 / 크래프트지 |
| 4. 여행 | 76~110 | 10x10 → 12x12 | 비행기, 자전거, 등대, 텐트 | 먹 / 한지 |
| 5. 밤하늘 | 111~150 | 12x12 → 15x15 | 달, 로켓, 부엉이, 별자리 | 흰 분필 / 칠판 |

- 출시 후 업데이트: 챕터 단위(25~30레벨)로 추가. 이후 "오늘의 그림"(데일리 퍼즐) 모드 검토.

### 6.3 튜토리얼 (레벨 1~5)
규칙을 한 번에 하나씩, **강제 진행(손가락 가이드)** 으로 가르친다. 5x5 이하.
| 레벨 | 가르치는 것 |
|---|---|
| 1 | 숫자 칸은 칠 못 함 + `0`이면 주변 전부 비움 + 탭 조작 |
| 2 | 단일 숫자 (`3`, `4`) = 이어진 덩어리 |
| 3 | 여러 숫자 (`1 1`, `1 2`) = 떨어진 덩어리들 |
| 4 | 칠한 칸은 모두 이어져야 함 (고립 불가) |
| 5 | 2x2 금지 + 점 표시/드래그 소개. 이후 자유 플레이 |

- 레벨 6~10은 튜토리얼 없이 규칙 하나씩 응용하는 쉬운 레벨.
- 새 추론 기법이 처음 필요한 레벨에서는 짧은 팁 말풍선 1회.

## 8. 아트 방향성

### 추천: "스케치북" 콘셉트
게임 전체를 **누군가의 스케치북**으로 만든다. 퍼즐을 푸는 행위 = 스케치북에 그림을 그리는 것.

**이 방향을 추천하는 이유**
- 게임 설명이 곧 콘셉트다: "숫자를 따라 칠하면 그림이 된다."
- 흑백 선화 제약이 오히려 자연스럽다 (연필 스케치는 원래 흑백).
- **레벨마다 그림 에셋이 필요 없다.** 그림은 정답 데이터 자체이고, 썸네일도 런타임에 만든다. 필요한 건 종이 질감과 필기구 질감 몇 장뿐.
- 챕터마다 **종이와 필기구만 바꿔서** 컬러 없이도 변화를 준다 (연필 → 볼펜 → 사인펜 → 먹 → 분필).

### 비주얼 요소
| 요소 | 방향 |
|---|---|
| 배경 | 종이 질감 (챕터별: 흰 도화지, 모눈 노트, 크래프트지, 한지, 칠판) |
| 격자 | 연한 인쇄선 느낌. 숫자 칸은 살짝 다른 톤 |
| 칠한 칸 | 필기구 질감 스프라이트 3~4종을 무작위로 써서 손으로 칠한 느낌. 이웃 칸과 이어질 때 모서리를 둥글게 이어 "선"처럼 보이게 |
| 점 표시 | 작은 연필 점 |
| 숫자 | 깔끔한 산세리프 (가독성 우선) |
| UI 텍스트 | 본문 Pretendard, 제목·그림 이름은 손글씨체 (예: 나눔손글씨). 둘 다 OFL 라이선스라 상업 사용 가능 |
| 버튼/아이콘 | 종이 조각, 마스킹 테이프, 클립 모티프. 둥근 모서리 |
| 맵 | 스케치북 페이지 위에 연필로 그린 점선 길. 챕터 경계는 스케치북 표지 |
| 캐릭터 (선택) | 연필 캐릭터 하나가 맵의 현재 위치에 서 있음. 앱 아이콘에도 활용 가능 |

### 색
- 기본은 **종이색 + 필기구 색** 2톤. 강조색은 하나만 (예: 빨간 색연필 — 오류 표시, 알림 뱃지).
- 다크 모드 = 칠판/검은 스케치북 + 흰 분필.

### 사운드
- 칠하기: 연필 사각 소리 (짧은 샘플 3~4개 랜덤)
- 점: 톡
- 되돌리기: 지우개 슥
- 클리어: 종이 넘기는 소리 + 짧은 멜로디
- 배경음: 잔잔한 어쿠스틱/로파이, 챕터별 1곡

### 앱 아이콘
숫자 몇 개가 적힌 격자 위로, 연필이 고양이 같은 선화를 막 완성한 장면. "숫자 퍼즐 → 그림"이 아이콘 하나로 읽히게.

### 대안 (참고)
- **먹/한지 수묵화 풀 콘셉트**: 한국적이고 차별화는 강하지만, 캐주얼 유저에겐 무겁게 느껴질 수 있음 → 챕터 4 테마로만 쓰는 걸 추천.
- **미니멀 플랫 파스텔**: 제작은 가장 쉽지만 비슷한 퍼즐 앱이 많아 묻히기 쉬움.
